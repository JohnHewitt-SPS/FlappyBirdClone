# 4. ObstacleSystem

**Goal**: Scrolling obstacle (stalactite/stalagmite pairs) spawning, movement, gap sizing
**Est.**: 2h
**Dependencies**: 1

## Steps
- [ ] Create an Obstacle object (top/bottom stalactite-stalagmite pair with a gap)
- [ ] Spawn new obstacles at a fixed interval/distance off the right edge
- [ ] Move obstacles leftward each frame at a constant speed
- [ ] Remove obstacles once they scroll off the left edge
- [ ] Randomize gap vertical position within playable bounds

## Definition of Done
- [ ] Obstacles spawn continuously and scroll across the screen
- [ ] Gap position varies between spawns
- [ ] Off-screen obstacles are cleaned up (no unbounded memory growth)
