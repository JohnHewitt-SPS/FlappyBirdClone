# 5. CollisionDetection

**Goal**: Detect bat vs. obstacle and bat vs. floor/ceiling collisions, trigger game-over state
**Est.**: 1.5h

## Steps

- [ ] Stop bat/obstacle updates when game-over state is active

- [ ] Bat hitting floor or ceiling triggers game over
- [ ] Game loop halts gameplay updates once game-over state is set
